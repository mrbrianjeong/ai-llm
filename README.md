## Stock Analysis Script

This repository includes a simple Python script for basic company analysis of a given stock ticker using the [yfinance](https://github.com/ranaroussi/yfinance) library.

### Requirements
- Python 3
- yfinance (`pip install yfinance`)

### Usage
Run the script and provide a stock ticker symbol when prompted. For example:

```bash
python stock_analysis.py AAPL
```

The script displays company information such as sector, industry, market capitalization, valuation metrics, and moving averages based on one year of historical data.
